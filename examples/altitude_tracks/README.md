# Space Trace: 10 траекторий по высотам

Откройте `SpaceTrace_10_altitudes.qgz` в QGIS. Проект содержит 10 спутниковых трасс на одной карте: от низкой околоземной орбиты около 420 км до геостационарной около 35 800 км. Все данные лежат рядом с проектом; интернет для открытия не требуется.

**Время начала:** 2026-10-27T00:14 UTC. Для каждого объекта показан один полный оборот с примерно 181 временной точкой. Линии разорваны у антимеридиана, чтобы не пересекать всю карту. У почти геостационарного GOES 16 след на карте короткий — его исходное положение отмечено точкой с подписью.

В таблице слоёв `10 траекторий` — линии, `Начало каждой траектории` — подписи, `Временные точки и высота` — точки с точным временем, высотой и скоростью (скрыты для читаемости карты). Откройте таблицу атрибутов или инструмент «Определить объект», чтобы посмотреть значения. В каталоге `tle/` лежат 10 исходных TLE-файлов; их можно загрузить в плагин как локальные TLE-данные и построить новый интервал.

Источник орбитальных элементов: [Space-Track GP](https://www.space-track.org/documentation), актуальные записи на момент создания проекта. Фон стран: встроенная карта QGIS на основе [Natural Earth](https://www.naturalearthdata.com/). Положения рассчитаны Skyfield через вычислительный модуль Space Trace. Это демонстрационный снимок, а не прогноз для навигации или управления аппаратом. Для другого дня обновите элементы через API.
